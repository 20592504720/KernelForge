## 触发条件

环境迁移、跨平台差异、Python 虚拟环境、长路径、CRLF/LF、Git 安全目录或资源清理时使用。

## 执行流程

1. 盘点现有工作区、缓存、工具链、进程、磁盘和虚拟环境。
2. 复用可验证资源；对迁移逐文件比对 SHA256，明确链接、权限和行尾语义。
3. 清理前记录候选、唯一性、活动引用和回退证据；只执行限定删除。
4. 清理后重新盘点并保存证据，不改系统安全策略或全局 Git 配置。

## 验收标准

- Windows/WSL 结果和限制分别记录；路径、权限和行尾问题可重现。
- 未确认冗余的历史证据、唯一源代码、构建产物和环境不得删除。
