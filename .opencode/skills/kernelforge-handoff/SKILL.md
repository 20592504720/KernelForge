---

## 触发条件

任务暂停、代理切换、未提交修改、跨平台验证或需要恢复历史证据时使用。

## 执行流程

1. 记录路径、分支、HEAD、Tree、Git 状态、未提交差异和当前边界。
2. 保护未提交代码，导出完整补丁并核对历史报告、唯一产物和锁摘要。
3. 运行最小恢复验证，更新结构化 JSON 检查点、日志和 SHA256。
4. 用简体中文交接已完成、阻塞、未验证项、下一步和禁止项。

## 验收标准

- 新代理无需依赖上下文即可恢复，且不会误改正式工作区或覆盖既有成果。
- 检查点与实际 Git 状态、证据文件和退出码一致。
