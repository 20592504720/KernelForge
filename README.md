# KernelForge

A modular and extensible automated Android Linux kernel build framework.

## Project Status

Project initialization in progress.

## Planned Features

- Linux kernel 5.10, 5.15, 6.1, 6.6 and 6.12
- GKI and Vendor kernel build support
- KernelSU Official, KernelSU-Next and ReSukiSU integration
- Modular patch management
- SUSFS and optional kernel features
- Networking and ZRAM configuration
- Toolchain management
- GitHub Actions automated builds
- Build artifact packaging and release

## Development

This project is being rebuilt from the ground up. Features will be implemented and tested incrementally.
